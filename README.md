# Numeric HP Indicator (Fabric 1.21.4)

Минималистичный PvP-мод для Minecraft 1.21.4 на Fabric:
- **Под прицелом** показывает точное HP врага (например `14.73`), без лишних рамок и полосок.
- **Над хотбаром** (по центру снизу, над полоской сердец) показывает твоё текущее HP с учётом золотых сердец поглощения (`Absorption`).
- **Плавный градиент цвета** по мере потери здоровья: ярко-зелёный → салатовый → жёлтый → оранжевый → красный.
- **Настройка по клавише `H`**: перетаскивание мышкой (ЛКМ), изменение размера колёсиком мыши и переключение дробных/целых чисел.
- Все позиции привязаны к центру экрана и автоматически сохраняются в `config/hpbar.json`.
